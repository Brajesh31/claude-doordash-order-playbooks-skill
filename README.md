# DoordashOrderPlaybooks

Provides reusable decision playbooks for delivery ordering, substitutions, delays, missing items, refunds, and support escalation.

## What this skill covers

- Practical guidance for doordash order playbooks workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.

## Installation

Add this skill directory to the skills location supported by your AI coding assistant, then make the skill available to the assistant.

## Usage

Invoke the skill for tasks related to doordash order playbooks. Provide the relevant context, constraints, and expected outcome. Review generated changes before applying them.
