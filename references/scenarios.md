# Delivery Order Scenario Playbooks

## Before checkout
Confirm item availability, substitutions, fees, delivery address, and estimated arrival. If an essential detail is unclear, pause checkout.

## Restaurant preparation delay
- Capture the displayed status and time.
- Compare against the current estimate, not an earlier estimate.
- Ask support for the latest available status.
- Do not promise a revised arrival time.

## Missing or incorrect item
- Compare delivered items with the receipt.
- Record the affected item, quantity, and concise description.
- Keep packaging or photos only when useful and safe.
- Request the platform's available resolution without exaggerating.

## Damaged or spilled order
- Avoid consuming food if packaging integrity or contamination is in question.
- Photograph the condition if safe and practical.
- Record which items are affected.
- Request an appropriate review.

## Refund or credit follow-up
- Link the follow-up to the original order and prior case.
- State the amount and resolution already received.
- Ask for status rather than opening duplicate claims.
- Retain the final response and transaction record.
